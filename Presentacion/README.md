# Presentación de El proyecto

Recorrido interactivo para explicar el proyecto de realidad virtual. No modifica las escenas ni los scripts de Unity.

```bash
cd Presentacion
npm install
npm run dev
```

Abre la dirección que imprime Vite. Flechas para cambiar de pantalla, teclas 1–6 para saltar y N para las notas del presentador.

`npm run build` deja el sitio estático en `dist/`.
